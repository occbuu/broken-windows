# Results guide

This guide maps the analysis components to the archived machine-readable outputs. File names preserve those generated by the analysis pipeline.

| Analysis component | Main output files |
|---|---|
| Sample construction and validation | `results/tables/T00_verification.csv`, `results/tables/T1_descriptives.csv`, `results/tables/results_headline.json` |
| Complaint vocabulary and NMF topics | `results/tables/T2_request_types.csv`, `results/tables/T2b_domain_totals.csv`, `results/tables/T2_nmf_topics.csv` |
| Tract fixed-effects models | `results/tables/T3_multilevel_repeat.csv`, `T3_multilevel_repeat_nyc.csv`, `T3_multilevel_repeat_chi.csv` |
| Responsiveness interactions and simple slopes | `results/tables/T4_simple_slopes.csv`, `T4_simple_slopes_nyc.csv`, `T4_simple_slopes_chi.csv` |
| Mediation analysis | `results/tables/T5_mediation.csv` |
| Spatial dependence and spatial models | `results/tables/T6_morans_i.csv`, `T7_spatial_models.csv`, `T10_spatial_shap.csv` |
| Predictive performance and explainability | `results/tables/T8_ml_performance.csv`, `T9_shap_importance.csv`, `results/metadata/gnn_results.json` |
| July 2020 design | `results/tables/T11_did_july2020.csv` |
| Boundary checks | `results/tables/T12_borough_boundary_rd.csv`, `T12_ward_boundary_rd.csv` |
| Treatment-effect heterogeneity | `results/tables/T13_cate_by_disadvantage.csv` |
| House-value and crime cross-lags | `results/tables/T14_zhvi_crosslag.csv`, `T15_crime_crosslag.csv` |
| Chicago robustness suite | `results/tables/chicago_v1/` |

The PNG files in `results/figures/` visualize the corresponding estimates. They are results, not manuscript pages.
